## 📚 Key Learnings

**1. Golf**
* A bouncing path simulation can be entirely bypassed using modulo arithmetic. If a target is reachable in steps of $k$, the absolute distance from the starting point must be perfectly divisible by $k$. Testing both the forward starting point ($0$) and backward starting point ($N+1$) gives an instant $O(1)$ answer.

**2. Open the Dragon Scroll**
* To maximize the XOR of two binary numbers, you want to misalign their set bits ($1$s and $0$s) as much as possible. By counting the total available $1$s across both numbers, you can determine exactly how many bits can be set to $1$ in the final answer without simulating any actual bit-shuffling.

**3. Budget Allotment**
* When distributing a pooled resource to meet a minimum threshold, a greedy strategy is always optimal. Harvesting all surplus first, sorting the remaining deficient elements in descending order, and patching the ones closest to the threshold guarantees the maximum number of fulfilled constraints.
