## 📚 Key Learnings

**1. Chef and Subset**
* When dealing with an extremely small, fixed number of variables (like exactly 4), explicitly writing out all $2^N - 1$ subset combinations is completely viable and often executes faster than setting up an array and a recursive backtracking function.

**2. Bear and Milky Cookies**
* Validating sequence rules (like "A must be followed by B") only requires an $O(1)$ memory state tracker (`prev`) and a final check of the very last element to ensure the sequence didn't terminate in an invalid state.

**3. Chef and Secret Ingredient**
* When searching for "at least one" element that meets a condition, a simple boolean flag during the input stream is optimal; you must let the loop finish consuming the input to prevent corrupting the next testcase, making an $O(N)$ scan perfectly safe and efficient.
