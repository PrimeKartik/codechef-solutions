## 📚 Key Learnings

**1. Subtraction Game 1**
* A simulation that repeatedly subtracts the smaller number from the larger number until they are equal is simply the literal definition of the Euclidean algorithm. The answer is always the Greatest Common Divisor (GCD) of the entire array.

**2. Chef and Demonetisation**
* Coin change problems with specific even-number conditions can be solved in $O(1)$ time by using integer division for the bulk of the amount, and checking modulo remainders to resolve the odd/even edge cases.

**3. Avoid Fixed Points**
* You don't need to actually insert elements into an array or use dynamic lists to avoid fixed points ($A_i = i$). You can just maintain a virtual `pos` variable that increments extra times whenever an insertion is logically required, doing the job in a pure $O(N)$ scan.

**4. Split the Str Ing**
* If a valid string split $A + B$ exists where $B$ is a contiguous substring of $A$, then there *must* exist a valid split where $B$ is exactly length 1 (just the very last character). This reduces the problem to just checking if the final character exists anywhere else in the string.
