## 📚 Key Learnings

**1. Geometric Mean Inequality**
* When domain values are heavily restricted (like only `1` and `-1`), complex equations like $Y^2 = X \cdot Z$ simplify drastically. Since $Y^2$ is always $1$, the problem reduces to ensuring $X \cdot Z \neq 1$, which strictly means avoiding $A_{i-1} = A_{i+1}$. This transforms an algebraic puzzle into a simple frequency-matching and sequence-building task (e.g., building `1, 1, -1, -1...`).

**2. Chef and Notebooks**
* When searching a dataset for *any* item that satisfies multiple criteria (pages and budget), storing the items is unnecessary. Processing the stream on the fly with a single boolean flag guarantees $O(1)$ space complexity.

**3. Chef and Memory Limit**
* Tracking memory allocation spikes is effectively a "delta accumulation" problem. You only need to add to the total when the current state exceeds the previous state. Because these deltas sum up over $10^5$ queries, using `long long` is mandatory to prevent integer overflow.
