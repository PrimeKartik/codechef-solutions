## 📚 Key Learnings

**1. Ratio By 2**
* When trying to reach a $1:2$ ratio, decreasing the smaller value is mathematically twice as "cost-effective" in operations as increasing the larger value.

**2. Larger Smaller**
* The number of integers strictly between a set's minimum and maximum is simply `max - min - 1`, allowing an $O(N)$ boundary scan to replace checking every possible number.

**3. Buying New Tablet**
* Evaluating a secondary metric (Area) while strictly filtering by a primary constraint (Budget) is best handled by initializing a running tracker to `INT_MIN` and updating it only when both conditions are met.
