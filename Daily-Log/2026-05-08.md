## 📚 Key Learnings

**1. Closest Vowels**
* Complex string transformation paths can be simplified by identifying the mathematical midpoints; recognizing that only 4 specific consonants (`c, g, l, r`) have equidistant vowels reduces a combinatorial problem to a simple $O(N)$ occurrence counter.

**2. Doubled Distances**
* When a problem requires consecutive differences to strictly scale by a factor, sorting the array naturally forces the elements into the only valid monotonic (steadily increasing) progression, completely eliminating the need to generate complex permutations.

**3. Laddu**
* Sequential log-parsing problems are cleanly handled by treating the input stream as a state machine, using `strcmp` to route logic and accumulate global variables on the fly.
