## 📚 Key Learnings

**1. Distinct Substring**
* To pack $K$ distinct islands into a string, the optimal strategy uses the smallest possible lengths: $1, 2, 3... K$. The sum of these lengths is $K(K+1)/2$, plus $K-1$ separators. Calculating this minimum required length solves the problem in $O(1)$ time.

**2. Tourist Translations**
* Custom string mappings can be handled beautifully in $O(N)$ time by treating the character's relative alphabetical position (e.g., `char - 'a'`) as the direct index for the translated dictionary array.

**3. Little Chef and Sums**
* Complex mathematical definitions in a problem statement can often be algebraically reduced. `prefixSum(i) + suffixSum(i)` evaluates to adding every element once, plus counting $A_i$ a second time. Therefore, minimizing this sum is exactly the same as simply finding the minimum element in the array.

**4. Chef-Detective**
* In a hierarchical reporting structure (a directed tree), finding the absolute bottom-level members (leaf nodes) simply requires counting how many times each person is reported to. Anyone with a frequency of `0` is a leaf node.
