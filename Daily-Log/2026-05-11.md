## 📚 Key Learnings

**1. Magic Pairs**
* When an array contains entirely distinct elements, any randomly selected pair will always have exactly one element smaller than the other. This reduces a comparison-heavy problem into a pure $O(1)$ math formula: $\binom{N}{2}$.

**2. Temperature Balance**
* Transfer or flow problems between adjacent elements in an array can be optimally solved using a running prefix sum; the absolute value of the prefix sum at any index represents the exact "traffic" or bottleneck that must cross that specific boundary.

**3. Garden Squares**
* Searching for symmetrical squares in a grid doesn't require checking every combination of 4 coordinates. Anchoring the search to a single top-left corner and probing diagonally by a dynamic distance `d` drastically reduces the time complexity and prevents duplicate counting.
