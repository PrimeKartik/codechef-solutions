## 📚 Key Learnings

**1. Breaking Bricks**
* When dealing with a tiny, fixed subset (like $N=3$) where operations (like reversals) are free, you don't need a simulation or recursive algorithm; evaluating the mathematical endpoints (first two vs. last two) completely covers all possible states in $O(1)$ time.

**2. Lift Requests**
* Processing sequential 1D movements only requires tracking the current position (`prev`). Summing `abs(prev - source)` and `abs(source - dest)` cleanly calculates the total traversal distance in a single $O(Q)$ pass.

**3. Jewels and Stones**
* You don't need a massive array or complex hash map for basic character lookups. Since English letters fall tightly within the ASCII table, sizing a frequency array to `58` (the exact distance from 'A' to 'z') provides a perfectly optimized $O(1)$ lookup table.

**4. Good Pairs**
* The mathematical condition $GCD(x, y) = LCM(x, y)$ can only be true if $x = y$. Recognizing this identity transforms a heavy number-theory problem into a straightforward array frequency counting and combination ($\binom{N}{2}$) task.
